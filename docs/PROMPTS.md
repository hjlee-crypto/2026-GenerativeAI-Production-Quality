# Gemini 실습 프롬프트

> 아래 프롬프트를 순서대로 실행하세요. AI의 답변을 그대로 정답으로 간주하지 마세요. 데이터 표는 Colab 출력에서 복사해 붙여넣습니다.

## 1. 분석 설계 (10~20분)
```
당신은 제조업 생산관리·품질관리 데이터 분석 보조자입니다.
데이터 열은 date, line, planned_units, produced_units, defect_units, scheduled_hours, downtime_hours 입니다.
생산계획 달성률, 불량률, 시간당 생산량, 시간가동률을 분석하려고 합니다.
각 지표의 계산식, 분모, 집계 시 주의점, 추천 차트 3개를 표로 제시하세요.
OEE를 계산할 수 있는지와 부족한 데이터도 설명하세요.
```

## 2. 코드 점검 (20~40분)
```
다음 pandas 집계 코드가 올바른지 검토해 주세요.
특히 비율을 단순 평균하는 오류, 0으로 나누는 경우, 생산량과 불량 수량의 관계를 점검하세요.
코드: [Colab의 지표 계산 셀을 복사해 붙여넣기]
오류가 있다면 수정 이유를 설명하고, 기존 코드와 변경 부분을 비교해 주세요.
```

## 3. 결과 해석 (40~60분)
```
다음은 교육용 가상 제조기업의 생산라인별 분석표입니다.
[Colab의 라인별 요약표를 복사해 붙여넣기]
1) 계획 달성률이 낮은 라인과 불량률이 높은 라인을 구분하세요.
2) 숫자로 확인된 사실과 원인에 대한 가설을 구분하세요.
3) 추가로 확인할 현장 데이터 3가지를 제시하세요.
4) 제공된 표만으로 단정할 수 없는 주장을 명시하세요.
```

## 4. 개선 제안 (60~75분)
```
아래 분석 결과를 바탕으로 품질·생산관리 담당자에게 제출할 개선 제안서를 작성하세요.
[라인별 요약표와 파레토 상위 3개 유형을 붙여넣기]
형식: ① 문제 현황(수치 근거) ② 원인 가설(확정 표현 금지)
③ 추가 확인 데이터 ④ 우선 실행할 개선 조치 2개
⑤ 조치 후 추적할 KPI 2개.
데이터로 입증되지 않은 개선 효과 수치는 만들지 마세요.
```

기준을 넘는 라인 이름을 표시해 주세요. 기존 라이브러리만 사용하세요.
