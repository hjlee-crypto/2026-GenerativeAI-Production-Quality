# 왜 이 실습을 하는가?

## 현장 상황
3개 생산라인에서 생산계획 미달과 불량 발생이 보고되었다. 생산관리 담당자는 납기 차질을, 품질관리 담당자는 주요 불량과 변화 시점을 확인해야 한다.

## 목적
- KPI를 계산하여 문제가 큰 라인과 시점을 찾는다.
- 파레토 분석으로 불량 조사 우선순위를 정한다.
- AI 분석 결과를 독립적인 코드 계산으로 검증한다.
- 확인된 사실, 원인 가설, 추가 현장 데이터, 개선 조치를 구분한다.

## 결과물
문제 현황(수치 근거) / 원인 가설 / 추가 확인 데이터 3개 / 우선 점검 2개 / 추적 KPI가 포함된 개선 제안 1장.

## 80분 권장 운영
0~15분 문제와 목적 / 15~35분 Julius AI / 35~60분 Colab / 60~75분 Gemini / 75~80분 검증.
